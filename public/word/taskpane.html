Citation preferences

Check citations

Fix automatically changes supported citations and replaces bare URLs and hyperlink text with citation drafts in the chosen scope. URL lookups send link addresses to Bluebookr. Unsupported items are reported. Use Word Undo to reverse changes; source details still need verification.

Checks run locally. Whole-document mode scans body paragraphs and, when supported, footnotes and endnotes. Headers, text boxes, and comments are excluded. Automatic fixes cover standalone full citations; inline citations and short forms are flagged for manual review. Source accuracy is not verified.

Cite a URL

Only the URL is sent to Bluebookr. The source website is contacted to retrieve metadata.

Keep the cursor where you want the citation. Insertions and replacements can be undone in Word.
